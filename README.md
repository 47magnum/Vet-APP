# Veterinary Clinic Management System

A full-stack web application designed for veterinary clinics to manage patient records, schedule appointments, and organize medical documents in a centralized, easy-to-use interface.

## Features

- **Patient Management**: Create, search, and update patient records with details like name, species, breed, and owner contact information.
- **Appointment Scheduling**: Schedule, view, and manage appointments with a calendar interface and date range filtering.
- **Document Management**: Upload and attach medical files to patient records with persistent storage.
- **Search & Filter**: Query patients by name, ID, owner name, or phone number with real-time results.
- **Responsive UI**: Mobile-friendly interface built with modern React patterns.

## Tech Stack

- **Frontend**: React 18 + Vite (fast HMR, optimized builds)
- **Backend**: Node.js + Express.js with CORS and file handling
- **Database**: Supabase (PostgreSQL) with relational schema
- **File Storage**: Supabase Storage (S3-compatible)
- **Styling**: CSS with responsive design

## Key Implementation Details

### Backend Architecture
- RESTful API with endpoints for patients, appointments, and file management
- Supabase client initialized with service role key for secure database access
- Multer configured for in-memory file uploads with 50MB file size limit
- CORS enabled for frontend-backend communication
- Error handling and validation on all routes

### Database Schema
- **patients** table: patient info and owner details
- **appointments** table: appointment scheduling with foreign key to patients
- **files** table: stores file paths linked to patients for document management
- Relational queries using Supabase joins for efficient data fetching

### Frontend Features
- Component-based architecture with separate pages for home, patient creation, search, appointments, and calendar
- Form handling for patient and appointment creation
- Real-time file upload integration
- Calendar view for appointment visualization
- Search filtering with multiple query parameters

## Local Setup (Development)

### Prerequisites
- Node.js v16 or higher
- npm or yarn
- Supabase account (create free at [supabase.com](https://supabase.com))

### Step 1: Set Up Supabase Database

1. **Create a new Supabase project:**
   - Go to [supabase.com](https://supabase.com) and sign up
   - Create a new project (free tier is sufficient)
   - Wait for initialization (2-3 minutes)

2. **Create the database tables:**
   - Open your Supabase project dashboard
   - Go to **SQL Editor** → **New Query**
   - Copy and paste the following SQL:

```sql
CREATE TABLE patients (
  id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
  name TEXT NOT NULL,
  species TEXT NOT NULL,
  breed TEXT,
  owner_name TEXT NOT NULL,
  owner_phone TEXT NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE appointments (
  id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
  patient_id BIGINT REFERENCES patients(id),
  appointment_date TIMESTAMP NOT NULL,
  duration_minutes INT DEFAULT 30,
  reason TEXT,
  notes TEXT,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE files (
  id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
  patient_id BIGINT REFERENCES patients(id),
  file_path TEXT NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);
```

3. **Create a storage bucket:**
   - Go to **Storage** → **Create New Bucket**
   - Name it: `patient-files`
   - Make it **Private** (for security)
   - Click **Create Bucket**

4. **Get your credentials:**
   - Go to **Project Settings** → **API**
   - Copy your **Project URL** (this is `SUPABASE_URL`)
   - Copy your **Service Role Secret** (this is `SUPABASE_SERVICE_ROLE_KEY`)

### Step 2: Install & Run Locally

```bash
# Clone the repository
git clone https://github.com/47magnum/Vet-APP.git
cd Vet-APP

# Frontend setup
cd frontend
npm install
npm run dev

# Backend setup (in another terminal)
cd ../backend
npm install

# Create a .env file with your Supabase credentials:
cat > .env << EOF
SUPABASE_URL=your_supabase_project_url
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key
PORT=5000
NODE_ENV=dev
EOF

npm start
```

### Step 3: Access the Application

- **Frontend**: Open `http://localhost:5173` in your browser
- **Backend API**: Running on `http://localhost:5000`

You should see the home page. Try adding a patient, scheduling an appointment, and uploading files

## API Endpoints

**Patients**
- `GET /api/patients` — Get all patients
- `GET /api/patients/search?name=&owner_name=&owner_phone=` — Search patients by filters
- `POST /api/patients` — Create new patient (with optional file uploads)
- `PUT /api/patients/:id` — Update patient details

**Appointments**
- `GET /api/appointments` — Get all appointments
- `GET /api/appointments/range?start=&end=` — Get appointments in date range
- `POST /api/appointments` — Create new appointment
- `PUT /api/appointments/:id` — Update appointment
- `DELETE /api/appointments/:id` — Delete appointment

**Files**
- `POST /api/patients/:id/files` — Upload files to patient record

## Troubleshooting

**Backend won't start:**
- Check that `.env` file exists in the `/backend` folder
- Verify `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` are correct
- Make sure Node.js v16+ is installed: `node --version`

**Frontend can't reach backend:**
- Ensure backend is running on `http://localhost:5000`
- Check browser console for CORS errors
- Verify frontend is configured to call `http://localhost:5000/api/...`

**Files won't upload:**
- Check that `patient-files` bucket exists in Supabase Storage
- Verify bucket is set to **Private**
- Check backend logs for upload errors
